# crop-recommendation-system
This project predicts the best crop based on input conditions.
## Model Files
Download from:
- Crop Model (.pkl): [https://drive.google.com/file/d/17wyI5B7Z-HNQEa2DF_Xla4CWMIVF6wvE/view?usp=sharing]
- CNN Model (.h5): [https://drive.google.com/file/d/1Q7cz8G2g-BxE12GArCM9-1b4Gcepux60/view?usp=drive_link]
  ## Files
- app.py → Main application
- crop_model.py → ML logic
- cnn_model.py → CNN model
 ## setup
1. Install dependencies:
pip install -r requirements.txt
2. Run:
python app.py
 ## Tech Stack
Python, Flask, Scikit-Learn, TensorFlow/Keras
HTML, CSS, JavaScript for frontend
NumPy & Pandas for data processing
